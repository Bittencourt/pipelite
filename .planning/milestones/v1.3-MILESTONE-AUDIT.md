## The milestone's most transferable lesson

Across the last two phases, **six gates were found that could not fail**: a grep whose malformed
bracket class matched nothing (so it passed on an empty diff), a credential grep whose only hits were
its own file paths, count gates counting prose the plan itself ordered written, a `docker compose
--build` that hit the layer cache and never recreated the container, operator documentation whose
"authoritative" check printed the same success line for 0 or 20 migrations, and a 24-test suite that
CI never runs at all.

None was a bug in the product. Every one was a bug in the *checking*. What worked was making executors
**mutate their own gate and watch it go red before trusting it** — that practice found four of the six.

**A check that has never been observed failing has not been tested.**
