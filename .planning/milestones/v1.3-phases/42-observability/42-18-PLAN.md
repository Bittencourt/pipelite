Flip `no-console` to `error` and prove the phase, in the container.

Purpose: this is criterion 1's durable half and the whole phase's gate. Criterion 1 says "no bare
`console.*` calls remain in non-test source". Migrating 273 call sites satisfies that sentence for a
moment; the lint rule is what keeps it true, and without the rule the 274th call arrives next phase.

build for the phase's entire duration or scattered roughly fifty disable comments through the tree.

file and line — and its diff, being three small config entries, is the proof that all 273 sites are gone.

module-graph split that `/api/health`'s correctness depends on; the `globalThis`-key unit test in plan 02
is a labelled proxy for it. `src/lib/audit/actor-context.ts:38-39` makes the same point about the same
hazard: "every unit test passes because vitest has a single module registry."

Output: a flipped lint rule with a clean run, and a witnessed container.
