<scripted_helper>
Half of CFUI-01 can be checked without a browser, and it is the exact procedure that reproduced the
bug: forge a read-only admin session cookie from the container's own `AUTH_SECRET`, fetch
`/admin/fields/deal`, and look for the Add Field `<button>` in the server-rendered HTML.

Rules for using it:
- It is a **helper**, never a committed test — it needs a running container and reads a secret.
- Write it under the session scratch directory, not in the repo.
- Never print, log, paste or commit the token, and never write it into the SUMMARY.
- It is read-only: it performs no mutation.

Procedure (from RESEARCH § Code Examples): a small `.mjs` that calls `encode` from `@auth/core/jwt`
with the admin's id/role/email and salt `__Secure-authjs.session-token`, copied into the container
under `/app` so module resolution works, executed with `docker exec`, then used as a `Cookie:` header
on a `curl` of the page. Grep the response for the Add Field button text and for `"children":"$L`
in the embedded flight stream.
</scripted_helper>
</context>
