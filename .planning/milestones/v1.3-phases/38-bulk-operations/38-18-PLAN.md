<objective>
Wire selection into the Deals kanban: a checkbox on each open-stage card, a select-all in each open-stage
column header, and the bar, spacer and failure report on the board.

Purpose: `/deals` is a kanban, not a table — there is no `useReactTable`, so this is the ONE declared
exception to "selection lives in TanStack `rowSelection`": `kanban-board.tsx` owns a
`useState<Set<string>>`. It is also the surface where the 100-id cap is genuinely reachable: `/deals` has
NO pagination at all (`page.tsx` fetches every non-deleted deal in the selected pipeline with no limit),
there are 25,195 live deals, the largest single stage holds 10,495, and nine stages hold more than 300.
A per-stage select-all is therefore over-cap in the NORMAL case, not an edge case, so select-all caps at
`BULK_MAX_IDS` and says so through a dedicated copy key (D-07).
The card checkbox needs THREE propagation stops, each preventing a different concrete failure, and the
keyboard one is an accessibility requirement rather than an optimisation: without it, Space is consumed
by dnd-kit's `KeyboardSensor` and a keyboard user cannot select a deal at all.
Output: four edited files. A full Deals TABLE view is explicitly NOT built.
</objective>
