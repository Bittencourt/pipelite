  export interface SelectColumnLabels {
    /** bulk.selectRow — "Select {name}" */
    selectRow: (name: string) => string
    /** bulk.selectAllLoaded — ICU plural on count */
    selectAllLoaded: (count: number) => string
  }

  /** Pure. No React hooks. Unit-testable without a DOM. */
  export function buildSelectColumn<T>(
    labels: SelectColumnLabels,
    getLabel: (row: T) => string,
  ): ColumnDef<T, unknown>

  /** 'use client' hook. Resolves the two labels via useTranslations("bulk") and delegates. */
  export function useSelectColumn<T>(getLabel: (row: T) => string): ColumnDef<T, unknown>

Column definition contract (38-UI-SPEC § Surface 1):
  id            "select"
  size          44          — honoured by activity-list.tsx, which renders style={{ width: header.getSize() }}
  enableSorting false
  enableHiding  false
  header        the select-all checkbox in a `flex items-center justify-center p-2` wrapper
  cell          the row checkbox in the same wrapper
  position      FIRST column, prepended by each consumer

TanStack API (8.21.3, verified in node_modules/@tanstack/table-core):
  RowSelectionState = Record<string, boolean>
  table.getIsAllPageRowsSelected() / getIsSomePageRowsSelected() / toggleAllPageRowsSelected(v)
  row.getIsSelected() / row.toggleSelected(v) / row.getCanSelect()
Use the PAGE variants, never the AllRows variants: the Page variants operate on
`getRowModel().rows` — the final row model — which on Activities is the filtered set and is what the
bar's count must match.

Radix `CheckedState = boolean | "indeterminate"` (node_modules/@radix-ui/react-checkbox/dist/index.d.mts:11).
The `checkbox.tsx` Minus branch added by plan 38-05 is what makes `"indeterminate"` visually distinct.

test succeeds (probe run 2026-08-17), so `select-column.test.ts` can import this module directly as

      - The `p-2` wrapper is NOT optional: the `Checkbox` primitive is `size-4` (16px) and the wrapper

      - The `aria-label` names the RECORD, not the row: fifty checkboxes announcing "Select row" is
        useless; "Select Acme Ltda" is navigable.
      - `stopPropagation` on the wrapper's `onClick` is defence in depth, not a bug fix: the row's
        `onClick` is `rowProps(index).onClick`, which moves the keyboard cursor. Toggling a checkbox
        must have exactly one effect, and the guard survives any future change to what a row click does.
      - No `<label>` element and no `htmlFor` — the `aria-label` is the accessible name, and a visible
        label would put text in a 48px column.

    The HEADER renders the same wrapper (no `stopPropagation` needed — the header row has no row
    `onClick`) around `<Checkbox checked={table.getIsAllPageRowsSelected() ||
    (table.getIsSomePageRowsSelected() && "indeterminate")}
    onCheckedChange={(v) => table.toggleAllPageRowsSelected(!!v)}
    disabled={table.getRowModel().rows.length === 0}
    aria-label={labels.selectAllLoaded(table.getRowModel().rows.length)} />`.
      - DISABLED, not hidden, on an empty table: a header cell that appears and disappears makes the
        column widths jump between an empty and a non-empty result, and `checkbox.tsx`'s
        `disabled:opacity-50` already communicates the state.
      - Use the PAGE variants only. The `AllRows` variants would select filter-hidden rows and make
        the bar's count exceed the visible row count, which is exactly the defect page-scoped
        select-all exists to avoid (D-02).
