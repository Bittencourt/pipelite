## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client bundle → server-only module | Importing `dispatch.ts` from a `'use client'` component would pull `@/db` and `pg` into the browser bundle |
| server action → dispatch | The dispatch trusts that authorization already happened; it performs none |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-38-03 | Denial of Service | `BULK_MAX_IDS` | mitigate | One shared constant, enforced SERVER-SIDE in every bulk action (plans 38-11..38-14). | T-38-07 | Information Disclosure | `BulkFailureReason` | mitigate | A closed four-member union rendered through `bulk.reason.*`. No raw server error string can cross the client boundary, because the type has no string arm |
