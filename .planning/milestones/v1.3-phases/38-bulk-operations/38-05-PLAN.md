<objective>
Add an indeterminate visual branch to the vendored `src/components/ui/checkbox.tsx`, and gate it.

Purpose: `checkbox.tsx` renders ONLY `<CheckIcon />` inside `CheckboxPrimitive.Indicator`. Radix
renders the Indicator for `checked === "indeterminate"` as well as for `true`, so a partially
selected header checkbox would render a CHECK MARK — visually identical to all-selected. Shipping the
header select-all without this fix means "3 of 50 selected" and "50 of 50 selected" look the same,
and the accessibility tree already announces `aria-checked="mixed"` while sighted users get the wrong
information. This is the phase's only change to a shared primitive, and it must be provably
behaviour-neutral for the eight existing consumers.
Output: a two-icon Indicator with a `group/checkbox` marker, plus a comment-stripped source gate.
</objective>
