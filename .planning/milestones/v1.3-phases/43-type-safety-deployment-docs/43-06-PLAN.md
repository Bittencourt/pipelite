<objective>
Normalize the one log scope that carries a space, and add the gate that keeps it normalized.

Purpose: D-6. `src/lib/import/pipedrive-api-client.ts:42` is `log.warn("Pipedrive API", …)`. It was
harvested verbatim from the pre-existing `[Pipedrive API]` bracket prefix under Phase 42's own
"bracket-wins" rule, and plan 42-16 flagged it rather than changing it unilaterally; 42-18 deferred it
with a recommendation. It is the only scope in the codebase containing a space.

**The space is the genuinely harmful property.** Every other scope is a single greppable token —
`trash-prune`, `views/queries`, `api/v1/workflows/[id]` — and a scope with a space is awkward to grep
and inconsistent with the whole log stream. Normalize to `pipedrive-api`. One line, plus the comment
above it, which currently asserts something that will stop being true.

Kept as its own plan so the diff stays legible, exactly as D-6 asked.

Output: one changed argument, one corrected comment, and a shape gate over all ~280 scopes.
</objective>
