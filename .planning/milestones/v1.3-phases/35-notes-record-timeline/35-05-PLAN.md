Create `src/lib/timeline/cursor.ts`.

`encodeCursor({ occurredAt, id })`:
- Serialise `JSON.stringify({ t: occurredAt.toISOString(), i: id })` and
  `Buffer.from(json, 'utf8').toString('base64url')`. ISO-8601 with milliseconds is what preserves
  ordering precision; `toISOString()` always emits `.SSS`.

`decodeCursor(raw)`:
- Return `null` immediately for `null`, `undefined`, or `''`.
- Guard the input length (reject anything over, say, 512 characters) before decoding, so a
  multi-megabyte cursor cannot be parsed at all.
- `Buffer.from(raw, 'base64url').toString('utf8')` then `JSON.parse` inside a try/catch.
- Validate the parsed object with a zod schema: `t` must satisfy `z.iso.datetime()` (or
  `z.string().datetime()` on the installed zod 4.3.6 API — check which one this version exposes),
  and `i` must be `z.string().min(1).max(128)`. Use `safeParse`; on `!success` return `null`.
- Build the `Date` from the validated string and assert `!Number.isNaN(date.getTime())` before
  returning; return `null` if it is NaN.
- The function must never throw. Every parse path is inside try/catch and every invalid shape
  returns `null`.

Why this matters (T-35-02): the decoded values become SQL bind parameters in the assembler
(plan 35-08). Decode → zod → bind is the whole control. Nothing decoded here may ever be
interpolated textually into SQL.

Run until green. Commit as `feat(35-05): implement the timeline cursor codec`.
