<objective>
Build the single-entity core of `recalculateFormulas()` — the shared helper D-01 mandates — with dependency scoping, correctly shaped engine inputs, topological ordering, and error persistence. No cross-entity cascade yet; that is plan 34-04.

Purpose: this is the phase's centre of gravity and the D-07 TDD target. Every trap RESEARCH measured lives here: a missing JSONB key fabricates `Unknown field: X` (Pitfall 1), a wrapper value evaluates to a silent blank with no error at all (Pitfall 2), `extractDependencies` returns duplicates (Pitfall 6), arrays string-concatenate (Pitfall 7), and expressions are wholly unvalidated because `validateFormula` is dead code (Pitfall 9). Phase 32's H-01 regression — a real null-propagation bug that survived a fully green 455-test suite — is the evidence that this area needs tests ahead of code.

Output: `src/lib/formula-recalc.ts` recalculating one entity's formula fields correctly and provably narrowly, plus DB-free wrapper primitives in `formula-helpers.ts` that the CSV and webhook readers (plan 34-05) import without pulling in `@/db`.
</objective>
