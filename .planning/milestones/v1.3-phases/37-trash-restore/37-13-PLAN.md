Ghost and outline only — `/trash` has ZERO accent-filled controls, deliberately. A `variant="default"`
Restore repeated down fifty rows would put the accent on roughly 40% of the page. The page's primary

Behaviour:

  - Both restore buttons go `disabled` with `Loader2 className="size-4 animate-spin"` and
    `t('restoring')` while in flight; the other rows stay interactive. Track the in-flight row id in
    state so only that row's controls disable.
  - Restore success: `toast.success(t('restored', { name, list: tNav(tab) }), { action: { label: t('openRecord'), onClick: () => router.push(href) } })`,
    then `router.refresh()`. The toast is REQUIRED here and is not a violation of the "no success toast
    where the result is visible" rule — it is the case that rule was written to exclude, because a row
    vanishing from trash is ambiguous between restored and destroyed, so the toast must name the
    destination list.
  - Linked-restore success: `toast.success(t('restoredWithLinked', { count }))` — the ICU plural, because
    reporting only the row the user clicked would understate what happened.
  - Restore failure: `NOT_IN_TRASH` → `toast.error(t('error.alreadyPurged'))` followed by
    `router.refresh()` so the stale row leaves; `NOT_ADMIN` is not reachable here; anything else →
    `toast.error(t('error.restoreFailed'))` with the row left in place and the buttons re-enabled. Switch
    on the code; string-match nothing.
  - Purge: clicking `Delete permanently` opens a CONTROLLED `AlertDialog` (`open` / `onOpenChange`, no
    `AlertDialogTrigger`) holding the target row in state. Title `t('purgeDialog.title')`, description
    `t('purgeDialog.description', { name })`, cancel `t('purgeDialog.cancel')` ("Keep in trash", not
    "Cancel"), confirm `t('purgeDialog.confirm')` with
    `className="bg-destructive text-destructive-foreground hover:bg-destructive/90"`. The confirm's
    `onClick` calls `event.preventDefault()` first so Radix does not close the dialog mid-request, then
    runs the action inside `startTransition`; the confirm shows `Loader2` and `t('deleting')` while in
    flight and Cancel is disabled during it. `onOpenChange` refuses to close while pending.
    Success → close, `toast.success(t('purged', { name }))`, `router.refresh()`.
    Failure → close, `toast.error(t('error.purgeNotPermitted'))` for `NOT_ADMIN`, otherwise
    `toast.error(t('error.purgeFailed'))`; the row stays.
  - After any successful restore or purge, move focus to the table's wrapper `<div tabIndex={-1} ref={...}>`.
    Removing the focused button drops focus to `<body>` otherwise. The announcement rides Sonner's own
    live region; add no second `aria-live` region.

No hardcoded hex, no `bg-white`, no `text-black`, no `text-red-*` / `text-green-*` / `bg-red-*` /
