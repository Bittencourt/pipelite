## Trust Boundaries

|----------|-------------|
| schema source → generated migration SQL | Whatever is declared here becomes DDL executed against a database holding real customer CRM data in plan 33-03. A malformed or over-broad declaration crosses this boundary as executable SQL. |
| schema source → `drizzle/meta/*_snapshot.json` | The snapshot is the diff basis for every future migration. Divergence between schema and snapshot is what silently DROPs indexes. |
| schema module → the vitest suite | `src/db/schema/*.ts` is imported (or mocked) by 18 test files. A change to the exported table objects could break the suite, which SC-4 forbids repairing by editing tests. |
