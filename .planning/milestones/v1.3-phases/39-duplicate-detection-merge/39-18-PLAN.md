      unconfigured behaviour, which is the same safe direction 39-08 chose.

      `Segmento Organização` rows for `entity_type='organization'` (verified; recorded in

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `createOrganization` server action | A server action is a POST endpoint. Every field of `data`, including the new `customFields`, is attacker-controlled regardless of its TypeScript annotation. |
| `app_settings` + `custom_field_definitions` → `/organizations` page render | Admin-authored configuration decides which inputs render. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39G-01 | Tampering | `createOrganization`'s new `customFields` argument | accept | A hostile client can name ANY custom field key, not only the configured ones.
