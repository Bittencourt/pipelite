  presentation.** `setState` lives inside the async callback invoked by `setInterval`, never in the
  effect body - that placement is what satisfies K-7, and `react-hooks/set-state-in-effect` is
  severity 2 (ERROR) in this repo.
- **`progress-step.tsx:48-53` is a DEAD EFFECT with an empty body that never stops the interval.**
  P-3 requires the scan panel to genuinely stop polling on `completed`, `failed` and `cancelled`. Do
  not replicate the no-op. Clear the interval from inside the poll callback when a terminal status
  arrives, or tear the interval down through the effect's dependency - either is fine, a no-op is not.
- **`progress-step.tsx:63-67` renders a hardcoded `"Initializing import..."` in the null state.** The
  scan panel's equivalent comes from the catalog.
- **P-4, four states, four distinct renderings.** `idle`: the CTA plus `dedup.scan.backgroundHint`.
  `running`: `Loader2` (`text-primary`, `animate-spin`) plus `dedup.scan.running` at Heading
  typography, the progress bar, `dedup.scan.cancel` (`variant="outline"`) and the background hint.
  `completed`: `dedup.scan.lastRun` at Label typography muted plus `dedup.scan.rescan` plus the pair
  list. `failed`: `Alert variant="destructive"` with `dedup.scan.failed` / `dedup.scan.failedBody`
  plus `dedup.scan.rescan`.
- **P-5:** `dedup.scan.backgroundHint` is mandatory in BOTH `idle` and `running`. The single most
  likely user error is sitting on the page for minutes because nothing said they could leave.
- **P-6:** when the viewer is not the person who started the scan, render `dedup.scan.startedBy`
  beneath the bar and do NOT render the cancel button. The server action enforces it; this is the
  presentation half.
- **P-7:** the CTA is disabled while a scan of that entity type runs, and the disabled reason is the
  visible `running` state - never a bare greyed button with no explanation.
- **P-8:** no stat tiles and no per-phase breakdown. One track, one sentence, one relative timestamp.
  `progress-step.tsx`'s `grid grid-cols-2 md:grid-cols-4` of `text-2xl font-bold` counters is
  explicitly not the model.
- **The client launch is fire-and-forget:** generate `crypto.randomUUID()`, call the server action
  WITHOUT awaiting, and switch to the running state immediately, exactly as
  `pipedrive-api-wizard.tsx`'s `handleStartImport` does.
- **L-3, decided:** each pair renders as a `rounded-md border p-4` card, never a table row. A table
  forces the two records into columns; at 320px that is about 110px each, and `overflow-x-auto` would
  hide half the comparison behind a scroll the user has no reason to suspect.
- **L-4 anatomy, top to bottom:** the confidence `Badge` and the `dedup.reason.*` line at Label
  typography muted; record A - name as a `text-primary hover:underline` link to its detail page, then
  its distinguishing value at Label typography muted; record B identically; then a
  `flex flex-wrap gap-2` action row. **The two records are stacked, never side by side, at every
  viewport** (R-3).
- **L-5:** `dedup.review.merge` (`variant="outline"`) then `dedup.review.dismiss` (`variant="ghost"`
  with an `X` icon). Neither is primary-filled - N primary buttons on one screen is not a 10% accent.
- **L-6/L-8:** dismissal is one click with no confirmation and is reversible via `?dismissed=1`. On
  failure, `toast.error(dedup.review.dismissFailed)` and **the pair stays in the list** - never an
  optimistic removal that a failed write leaves invisible. `router.refresh()`, not local state
  mutation, because the list is server-rendered.
- **C-3:** confidence tiers are distinguished by WORDS first - `certain` is `Badge variant="default"`
  reading "Almost certain", `likely` is `Badge variant="secondary"` reading "Likely". Never a bare
  colour-only dot, never red/amber/green.
- **R-4:** every flex row that can grow carries `min-w-0`. A flex item's default `min-width: auto` is
  the mechanism behind every overflow Phase 45 measured.
- This plan touches `src/app/duplicates/page.tsx` for the SECOND time (plan 39-11 created it). That is
  deliberate: 39-11's diff is a security boundary, this one is a layout.
- No Docker rebuild is paid here. Plan 39-17 pays it and runs Playwright once every UI edit has
  landed.
