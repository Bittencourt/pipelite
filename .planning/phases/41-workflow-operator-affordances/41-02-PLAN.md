<objective>
Extract the two decision points that WFOPS-01 and WFOPS-02 turn on into pure, database-free modules
with total functions, and gate them test-first: "does this URL want to see test runs" and "is this run
replayable, and what does its replacement run look like".

Purpose: both decisions are currently inline in a server component or nowhere at all, and both are
where the requirements are actually satisfied or broken. `?dryRun=2` must not be truthy; a `completed`
run must not offer a replay. Neither claim is testable while it lives inside an async server component
that opens a database connection. 41-VALIDATION.md Wave 0 names both test files, and
`__tests__/replay.test.ts` currently has no module to import — this plan creates it.
Output: `src/lib/workflows/runs-filter.ts`, `src/lib/workflows/replay.ts`, and two unit gates.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL → server component | every value in `searchParams` is attacker-authored and reaches `parseRunsSearchParams` first |
| stored `workflow_runs.triggerData` jsonb → a new run | a blob written by an older trigger path is untrusted input on read, and a replay hands it straight back to the engine |
| this module → the browser bundle | `status-filter.tsx` is `"use client"`, so anything imported at runtime here ships to the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-07 | Information disclosure | `parseRunsSearchParams` `showDryRuns` | mitigate | strict equality against `SHOW_DRY_RUNS_VALUE` (`"1"`), asserted directly for `"2"`, `"true"`, `"yes"`, `"01"`. A `Boolean(sp.dryRun)` implementation would let any crafted value reveal rows the default hides |
| T-41-08 | Tampering | `parseRunsSearchParams` status membership | mitigate | membership tested against a frozen array / `Set`, never a property lookup, so `__proto__` and `constructor` are ordinary non-members. Asserted, including that the returned object's prototype is `Object.prototype` |
| T-41-09 | Denial of service | `parseRunsSearchParams` page | mitigate | `MAX_PAGE_DIGITS` bounds the digit count so a megabyte value cannot reach an `OFFSET` or a log line, and the result is clamped to ≥ 1. Asserted with a 1 MiB input |
