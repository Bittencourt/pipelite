Build the background job's state layer: the `dedup_scans` row, its CRUD, and the boot-time reaper
that stops a container restart from disabling the scan button permanently.

<key_facts>
- **The guard must be adapted, not copied.** `createImportState` refuses when ANY session has
  `status = 'running'`, with no entity-type scope. For dedup that would let one running organization
  scan block a people scan, contradicting UI-SPEC P-7 which disables the CTA "of that entity type".
  The dedup predicate is `and(eq(dedupScans.status,'running'), eq(dedupScans.entityType, entityType))`.
- **`cancelPipedriveImport` checks authentication but never ownership** — it never compares
  `state.userId` to the caller. UI-SPEC P-6 forbids one user cancelling another's scan. The
  ownership comparison belongs in the server action (plan 39-11), but `cancelScan` in this module
  must expose `userId` so the action can make that comparison. State that split explicitly.
- **`instrumentation.ts` is fragile and has already failed in production.** `Dockerfile:24` copies
  the built `instrumentation.js` into `.next/standalone` with a step ending in `2>/dev/null || true`,
  so a build whose chunk layout changes fails silently. That exact breakage killed all four
  processors on 2026-08-08 while every test passed. **Verification must be behavioural** — grep the
  container log for a startup line — never a unit test asserting the function is imported.
- **The existing reaper logs only when `total > 0` and prints no startup line at all.** A behavioural
  gate is impossible against that shape, so `cleanupStaleDedupScans` must log unconditionally, once,
  with a fixed prefix.
- `docker compose logs` is intercepted by the RTK hook and summarised into an error/warning digest
  that HIDES startup lines. Use `rtk proxy docker compose logs app` for raw output.
- The container serves a baked image with no volume mount, so `instrumentation.ts` changes are
  invisible until `docker compose up -d --build app`. **This plan pays one rebuild.** Phase 45
  budgeted one and needed four; if this rebuild exposes a defect, pay another rather than weakening
  the gate.
- Fail-closed posture (S-5): nothing in this module throws to a caller except `createScanState`'s
  documented concurrency refusal. Every read fails into a value the page can render. Logs carry
  identifiers and bounds only, never record contents (T-37-09).
</key_facts>
