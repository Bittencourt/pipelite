resolves the owner as `owner_id || ctx.userId`, so a caller can name someone else.

plan 48-06 — the live distribution cannot discriminate, all 79,022 activities belong to one user).

base-project test that renders the captured `where` back to SQL so the scope is observable in CI.
</objective>
