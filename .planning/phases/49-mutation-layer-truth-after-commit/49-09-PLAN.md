**This milestone's one rule governs this plan: a gate with no recorded red observation is treated as
NOT DELIVERED.** v1.3 shipped six gates that could not fail; v1.4 has now found twelve more, two of
them inside Phase 48's own fix passes, and one of those was a SQLSTATE mapper that never fired while 24

processor "Starting" line is a vacuous freshness check. Any behavioural claim about the container needs
`docker compose up -d --build` followed by an assertion that the image id CHANGED.

by decision, there is no `/api/v1` file route and CONTEXT.md forbids inventing one, so an HTTP-level
SC-1 probe needs a browser session cookie. **SC-1's behavioural proof is therefore plan 49-06's, at the
handler level against real PostgreSQL and a real filesystem.** Say so; do not dress a 401 smoke check
up as a criterion proof.
