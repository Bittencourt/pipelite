| a record's `customFields` JSONB → a filesystem path | a stored `storedName` is interpolated into a path; the column is a data surface, and a poisoned value crosses into `unlink` |

| the test process → the developer's own filesystem | a containment bug in the helper, exercised by a test, deletes outside the sandbox |
