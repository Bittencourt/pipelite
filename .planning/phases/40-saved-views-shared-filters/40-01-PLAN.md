<objective>
Create the URL vocabulary for saved views: one client-bundle-safe module that owns the per-entity
filter whitelist, the `?view=none` escape serialiser, and the **two** filter predicates that keep
Phase 38's unbounded-export prohibition intact.

Purpose: six `"use client"` modules and four server components must agree, byte for byte, on what a
view may contain and on when an export is allowed. Two copies of that list is the T-37-03 defect
class. This module is also the only place where `hasSaveableFilter` and `hasExportableFilter`
diverge, and that divergence is the whole guard.
Output: `src/lib/views/types.ts`, `src/lib/views/url-params.ts`, and the unit gate V-40-6.
</objective>
