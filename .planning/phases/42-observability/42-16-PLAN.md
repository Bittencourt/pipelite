<migration_contract>
Signature: `log.<level>(scope, msg, ctx?)` — exactly three arguments, the error ALWAYS under `ctx.err`.
Import: `import { log } from "@/lib/log"`.
Level map: `console.error`→`log.error`, `console.warn`→`log.warn`, `console.log`→`log.info`,
`console.info`→`log.info`. **A warn stays a warn and an info stays an info.**

**Scope rule.** A `[bracket]` prefix always wins, harvested verbatim. Otherwise derive from the module
path: strip the leading `src/`, strip the file extension, keep every remaining segment. For files under
`src/app/` the boilerplate `app/` segment is also stripped; `lib/` and `components/` are meaningful and
are kept. Worked examples: `src/lib/redis.ts` → `lib/redis`;
`src/lib/notes/authorize.ts` → `lib/notes/authorize`;
`src/components/custom-fields/lookup-field.tsx` → `components/custom-fields/lookup-field`.

Note this is slightly longer than PATTERNS' illustrative `custom-fields/lookup-field`. The full-path form
is used deliberately, for consistency with every other non-`app/` file in the phase; flagged here so a
reviewer does not read it as drift.

**Message rule.** The trailing `:` leaves the message. Interpolated and interleaved label/value pairs
collapse into named `ctx` keys. **Never add a value that was not already in the string or in the object
already being logged.**

**Control flow rule.** Byte-for-byte equivalent. Swallow-and-log catches keep swallowing; return shapes
and null-returns unchanged.

**Style rule.** Every client component and `pipedrive-api-import-actions.ts` use single quotes. Match the
surrounding file; the repo is mixed. Do not reformat.
</migration_contract>
