<migration_contract>
Signature: `log.<level>(scope, msg, ctx?)` — exactly three arguments, the error ALWAYS under `ctx.err`.
Import: `import { log } from "@/lib/log"`.
Level map: `console.error`→`log.error`, `console.warn`→`log.warn`, `console.log`→`log.info`,
`console.info`→`log.info`. **A warn stays a warn.**

**Scope rule**, identical to plans 10, 11 and 14. A `[bracket]` prefix — inline or interpolated from a
module constant — always wins. Otherwise derive from the module path: strip the leading `src/`, strip a
leading `app/`, strip a trailing `/page.tsx` or the file extension, keep every remaining segment
verbatim including dynamic segments. Worked examples: `src/app/notes/actions.ts` → `notes/actions`;
`src/app/workflows/[id]/runs/[runId]/page.tsx` → `workflows/[id]/runs/[runId]`.

**Message rule.** The trailing `:` leaves the message. The prefix interpolation disappears. Every other
interpolated value moves into a named `ctx` key and the message becomes fixed. **Never add a value that
was not already in the string.**

**Constant deletion.** After a file's last site migrates, delete its `LOG_PREFIX`, having first grepped
for other uses.

**Control flow rule.** Byte-for-byte equivalent. Swallow-and-log catches keep swallowing; return shapes
and redirects unchanged.
</migration_contract>
