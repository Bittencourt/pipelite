## CFUI-01, the repo-wide asChild gate (Phase 44)

src/app/admin/fields/[entityType]/__tests__/rsc-boundary.test.tsx walks EVERY non-test .tsx under
src/, finds every file whose source contains the literal string asChild>{children} (the "definers"),
extracts their exported component identifiers, and FAILS if any file that renders one of them is not
a 'use client' module.

Consequences for this plan:
1. The 'use client' directive must be the FIRST non-comment token of all three files.
2. DeleteNoteDialog must take open and onOpenChange props and render NO AlertDialogTrigger and NO
   children forwarding. That keeps it out of the definer set entirely, so the rule never engages for
   it. This is the src/app/admin/webhooks/delete-dialog.tsx shape. Copy it, not a trigger-forwarding
   variant.
3. The gate matches a LITERAL string with no whitespace. Prettier reformatting would make a file
   invisible to the gate. Never rely on formatting for safety.
4. Run the gate after every new .tsx in this plan.
</hard_constraint>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| note content from storage to the DOM | Content is arbitrary user text, including text migrated from an external Pipedrive import |
| client component to server action | All three components call server actions; the UI's permission checks are cosmetic and the server decides |
| RSC boundary | A React element crossing into a Radix asChild slot returns null silently at runtime, with no throw and no warning |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-05 | Tampering | stored XSS via note content | mitigate | Rendered as a React text child inside a paragraph with whitespace-pre-wrap and break-words. No dangerouslySetInnerHTML anywhere, grep-gated. No markdown renderer exists to get wrong, because rich text is CONTEXT-locked out (D-03) |
| T-35-03 | Elevation of Privilege | hidden Edit and Delete buttons mistaken for the access control | mitigate | canManage only hides UI. Enforcement is server-side in plan 35-09 and plan 35-10, and an explicit code comment records this so a future reader does not weaken the server check |
| T-35-30 | Denial of Service | a silently broken RSC boundary rendering nothing with no error | mitigate | The Phase 44 class-wide gate is run after every new .tsx in this plan; DeleteNoteDialog is deliberately built as a non-definer with open/onOpenChange props |
| T-35-31 | Repudiation | a failed save silently losing the user's typed text | mitigate | The failure path retains the draft and toasts notes.error.saveFailed, whose copy states the text is still in the box. Acceptance criteria require the clear to live only in the success branch |
| T-35-SC | Tampering | npm installs | accept | Zero packages installed. Every primitive used here is already vendored in src/components/ui/ and components.json declares an empty registries object |
