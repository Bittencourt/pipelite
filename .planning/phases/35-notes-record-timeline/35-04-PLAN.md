  whitespace is stripped but internal `\n` survives.

  query predicates downstream and there is no pg enum or check constraint behind it, so zod is the
  only guard (T-35-04).

  keyed by `EntityType`, and a `db.query[...]` dispatch for the existence check. The parent lookup
  filters `and(eq(table.id, entityId), isNull(table.deletedAt))`. `entityId` carries NO foreign key,
  so the database will not catch a dangling reference — this check is the only defence.
- This module does NOT import `@/lib/events` and emits nothing. Adding a `note.created` event is
  CONTEXT-locked out (D-15): a 14th event type would drag in trigger-config UI, the matcher, both
  existing subscribers' `ALL_EVENTS` arrays, and the API docs.

| Boundary | Description |
|----------|-------------|
| caller (action / route) → mutation layer | Input reaching this module is already authenticated but NOT yet authorized; content is fully untrusted user text |
| mutation layer → database | `entityType` reaches a query predicate; `content` reaches a bound parameter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-04 | Tampering | cross-record note injection via a mismatched `entityType`/`entityId` | mitigate | `z.enum` on the four literals plus a mandatory parent-existence lookup filtered on `isNull(deletedAt)`; asserted by `notes.test.ts -t "dangling"`. `entityId` carries no FK so the database cannot catch this |
| T-35-06 | Information Disclosure | soft-deleted notes returned by a read | mitigate | `findNoteById` and every read carry `isNull(notes.deletedAt)` explicitly; the partial index encodes but does not enforce the predicate |
| T-35-07 | Denial of Service | unbounded note content | mitigate | `NOTE_CONTENT_MAX = 200000`, above the observed 131,505-character maximum and below an abuse ceiling; paired with the existing API rate limiter on the `/api/v1` surface (plan 35-10) |
| T-35-10 | Information Disclosure | raw Postgres error text returned to a caller | mitigate | try/catch in every exported function; detail to `console.error`, generic string to the caller; asserted by the "generic error" test |
| T-35-18 | Elevation of Privilege | authorization silently living in the mutation layer where only one of two call sites would use it | mitigate | This module contains zero occurrences of `session`/`role`, asserted by grep gate; the shared helper in plan 35-07 is called from both the action and the route |
| T-35-SC | Tampering | npm installs | accept | Zero packages installed |
