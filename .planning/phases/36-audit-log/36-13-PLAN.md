  <action>
    Create `src/components/timeline/audit-entry.tsx` as a `'use client'` module using
    `useTranslations("audit")` and `useFormatter()`.

    **Rail** — actor kind: `user` → `Avatar size-8` with initials; `workflow_run` → `bg-muted size-8
    rounded-full` circle with `Workflow`; `api_key` → `Key`; `import` → `Download`; `system` → `Cog`
    (not `Bot` — nothing here is an AI and the icon must not suggest one). All rail icons carry
    `aria-hidden="true"`.

    **Line 1**, in this order: actor name (Label role) resolved per the UI-SPEC table, with the
    fallback being the KIND LABEL and never a guess; the per-entity predicate string
    `audit.entry.{action}.{entityType}` — twelve separate keys, never a `{entity}` placeholder,
    because Spanish and Portuguese inflect the demonstrative with the noun's gender; the `<time>`
    element; and — only when `actorKind !== 'user'` — a
    `<Badge variant="secondary" className="gap-1 font-normal">` carrying the icon plus the translated
    kind label. **The badge is not decoration.** The rail glyphs are `aria-hidden`, so the badge is
    the only text carrier of the actor kind, and SC-3 is satisfied in text rather than in pixels.

    A `workflow_run` actor name is a `Link` to `/workflows/{workflowId}/runs/{runId}` with
    `text-primary hover:underline`. When `workflowRun` is null the plain kind label renders with no
    link — never a broken link.

    **Line 2** — a `<dl className="mt-1 space-y-1">` with one
    `<div className="flex flex-wrap items-baseline gap-2">` per change: `<dt>` at
    `text-muted-foreground text-xs`, `<dd>` at `text-sm leading-normal min-w-0 break-words` holding
    the `from` value (muted), an `sr-only` `audit.value.changedTo` span, an `aria-hidden` inline
    `ArrowRight`, and the `to` value (foreground).

    **The single most important colour rule in this phase is a prohibition: no red/green diff
    colouring.** A field changing is neither a loss nor a gain, and green/red imports version-control
    semantics into a record of business facts — it would turn every routine owner reassignment into
    something that reads like an error. The before/after signal is muted-vs-foreground plus the
    arrow. No hardcoded hex, no `bg-white`, no `text-black`, no `text-red-*`, no `text-green-*`
    anywhere in this file.

    On a `created` entry `from` is null: omit the arrow AND the `sr-only` connector, rendering only
    `to`. A create is an initial state, not a transition; drawing an arrow from nothing would be a
    fiction. On a `deleted` entry `changes` is empty: render no `<dl>` at all.

    **Value rendering** follows the UI-SPEC's exhaustive table without deviation: `empty` renders the
    word from `audit.value.empty` in `italic text-muted-foreground` (never `null`, never `—`, because
    an em-dash is indistinguishable from one a user typed); `number` uses `format.number` with no
    currency symbol; `boolean` uses `audit.value.yes`/`audit.value.no` and never the literals;
    `date` uses `format.dateTime` with the specified option sets and NOT `RelativeTime` (a diff needs
    the value that was stored, not how long ago it was); `list` uses `format.list` then truncates the
    joined string; `reference` renders its label or `audit.value.unavailable` — an id is never shown;
    `files` uses the ICU plural; `json` renders the compacted string with NO JSON viewer.

    Every string-producing case passes through `collapseAndTruncate` from `@/lib/audit/present`, and
    the truncated element carries a native `title` — NOT a Radix Tooltip: `tooltip.tsx` is not
    vendored and `components.json` declares an empty `registries` object.

    **Progressive disclosure**: three field rows by default. When `changes.length > 3`, a
    `Button variant="ghost" size="xs" className="text-muted-foreground mt-1"` with
    `aria-expanded` and `aria-controls` pointing at the `<dl>`'s `id={`audit-fields-${entry.id}`}`,
    labelled `audit.showMoreFields` with the remainder count (the accessible name states the count,
    never a bare "Show more"). Use plain `useState` plus a conditional render — deliberately NOT the
    vendored `Collapsible`, for exactly two reasons: there is no animation requirement and a
    conditional render is one line. **Do not cite CFUI-01 as a third reason.** That gate governs a
    server component passing an element into a client `asChild` slot; this file is `'use client'` end
    to end and reached through Phase 35's client `TimelineList` subtree, so it would not engage. A
    wrong reason quoted as precedent by a later phase is worse than no reason.

    **Defensive state**: an `updated` entry whose `changes` array is empty renders line 1 plus a
    single muted `audit.entry.noVisibleChanges` line. The subscriber should not create such rows
    (36-11 returns early on an empty diff), but a renderer that silently draws an empty `<dl>` would
    make that bug invisible.

    Deliberately NOT copied from the analog: the `FROM_SLOT`/`TO_SLOT` sentinel machinery at
    `stage-change-entry.tsx:63-100`. That exists because a translated sentence had to host React
    badges; the audit `<dl>` is label/value with no interpolated elements, so importing it would be
    cargo cult.

    Custom field labels are user-authored text rendered as React TEXT children, which React escapes.
    Raw-HTML injection props must never appear in this file, and it is grep-gated to zero
    occurrences. Do not name the gated prop in a doc comment — a comment that names a token gated at
    zero is itself a gate violation, and that fired three times in Phase 35.
