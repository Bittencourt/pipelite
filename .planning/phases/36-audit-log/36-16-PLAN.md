    Title treatment:
    - live record → `<Link href={/{entityType}s/{entityId}}>` at
      `text-sm leading-tight font-semibold text-primary hover:underline`

    `toast.error`.

    Field count uses the `audit.run.fieldCount` ICU plural at `text-xs text-muted-foreground`, and is
    OMITTED entirely when `action === 'deleted'` — a tombstone has no field count.

    Timestamp is `<time dateTime title>` wrapping `RelativeTime` at `text-xs text-muted-foreground`.

    States: has-records renders the list; empty renders `audit.run.empty` in the bordered panel with

    otherwise-English page for es-ES and pt-BR users. That seam is the right trade. **Do NOT "fix" it
    by translating the rest of the run page** — that is unrelated scope.

    RSC boundary: this is a server component, so it renders only `Link`, `Badge` (without `asChild`),
