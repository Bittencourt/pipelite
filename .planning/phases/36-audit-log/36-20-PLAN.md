       SHOULD trip it — `import { getCurrentActor } from "@/lib/audit/actor-context"`,
       `from '@/lib/audit/diff'`, `from "@/db/schema/audit-log"`, `require("@/lib/audit/prune")`,
       a bare `auditLog` identifier reference, `buildChanges(`, `runWithActor(`.

       explicitly, since `stripComments` removes it and the assertion is what proves the stripping
       runs), a variable named `auditedFields` that is not the schema table, and the word `audit`
       appearing inside an unrelated string literal.

       happened: three of seven call sites had grown a named handler and the detector was blind to
       it.

    negative source assertion is trivially invalidated by a comment that merely mentions the code it
    forbids — the exact class of self-invalidating gate that lets a regression back in.
