<objective>
Repair CFUI-01 structurally: stop passing a React element across the RSC boundary (D-44-01).

Purpose: the deal admin page ships 155 definition rows in the same props object as the Add Field
`<Button>` element. React Flight's per-row budget is 3200 bytes; once the data prop blows past it,
the next element it serializes is deferred into its own row and replaced with `"$L19"`. Radix's
`SlotClone` sees a non-element behind `asChild` and returns `null` silently. There is currently no
UI path to create any custom field on a deal. The repair is to move the trigger into a `'use client'`
wrapper so only serializable data crosses — the pattern already proven at
`src/app/workflows/new-workflow-button.tsx` and at `fields-list.tsx`, which renders the same 155-row
prop correctly because it is client-to-client.

Output: `AddFieldButton` and `RestoreFieldButton` client wrappers, a `page.tsx` that renders no
`FieldDialog`, and the structural half of SC-5/SC-6 as executable gates.
</objective>

The two broken call sites in `page.tsx`, a **server** component:

```tsx
// line 46 — the header trigger (155 definition rows alongside an element child)
<FieldDialog entityType={...} availableFields={activeFields as CustomFieldDefinition[]}>
  <Button><Plus className="h-4 w-4 mr-2" />{t('addField')}</Button>
</FieldDialog>

// line 78 — the archived-field restore trigger, inside archivedFields.map(...)
<FieldDialog field={field as CustomFieldDefinition} entityType={...}>
  <Button variant="ghost" size="sm">{t('restore')}</Button>
</FieldDialog>
```

Both are the same defect. `serializedSize` accumulates across the whole row, so by the time the
serializer reaches the archived section the budget is long gone — the restore triggers on a
155-definition entity are dropped for the same reason, they are simply unobservable today because
`deal` currently has no archived definitions. Move both.

The authorization gate that must NOT move, `page.tsx:18-21`:

```tsx
const session = await auth()
if (!session?.user || session.user.role !== 'admin') { notFound() }
```

i18n: `t` comes from `getTranslations('admin.customFields')` (server-side). Resolve the label strings
on the server and pass them as string props — smaller payload, and the i18n call stays in one place.
