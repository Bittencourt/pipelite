<objective>
Make the save path return the values the server just computed, so the client has something correct
to display.

Purpose: CFUI-02's root cause is two-part. Part B is that `/api/custom-fields/save` answers
`{ success: true }` with no data, so the client's `localValues` can never learn the recomputed
formula wrapper and the display stays pinned to page-load state. `recalculateFormulas` **already**
returns `{ customFields, evaluations }` — `saveFieldValues` throws it away. This plan stops throwing
it away. The client-side merge is plan 44-07; this plan is the server half and is independently
verifiable.

Output: `saveFieldValues` returns `{ success: true, values }`; the API route needs no change.
</objective>
