<objective>
Close the two adjacent client/server evaluator divergences the research pass found (D-44-04).

Purpose: CFUI-04 — `activities/[id]/page.tsx` passes no `entityAttributes`, so an activity formula
using `{{Title}}` or `{{DueDate}}` errors in the browser while Postgres holds the right value. The
other three detail pages pass them. CFUI-05 — `evaluateFormula`'s resource bound is an opt-in 4th
argument and is completely inert unless passed; Phase 34's D-18 passes it on every server call site,
and the browser call sites pass nothing, so an admin-authored `while(true)` wedges the user's tab.
Both are the same class as CFUI-03 and both are cheap; the user put them in scope explicitly.

Output: activity formulas resolve native fields; the browser evaluator is bounded exactly like the
server; both are guarded by tests that would have caught the original omissions.
</objective>
