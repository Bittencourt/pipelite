<objective>
Prove the four remaining criteria against 46,054 real organizations, as a real non-admin, through the
real action — and then break the fix and watch the proof collapse.

Everything before this plan is arithmetic and structure. This is the plan that answers the roadmap.

**SC-1's subject is measured at scale, and the worst case is not the one the roadmap names.**
`search=a` matches 44,254 of 46,054 organizations (96.09%). But every row in all four tables is owned
by one admin user, and `owner` is in `EXPORTABLE_FILTER_KEYS.deal` — so `/deals` with
`owner=ef4acac9-e860-4e71-9db5-ddaa2808cb9f` returns **25,195 of 25,195 = 100.00%, under the 50,000
cap**. That is a live second instance of WR-04, on a different key, worse than the headline. Both are
proven refused.

**SC-2 cannot be built on `owner` or `assignee`, and the file must say why.** `owner` returns 100% on
all four tables and `assignee` returns **zero** rows on both deals and activities (`deal_assignees` is
empty, `activities.assignee_id` is NULL for all 79,022 rows). A "narrow export still completes" proof on
either passes on a whole set or an empty one — the exact vacuity this milestone keeps finding. SC-2 uses
`search=ltda` (13,355 rows, 29.00%) and an activity `type` filter, and asserts the CSV's parsed row
count, not merely `success: true`.

**SC-4 is the criterion most likely to be faked and it says so itself:** *"widen a filter step by step
until it trips, and observe the refusal at the boundary. A guard whose threshold nobody has crossed on
purpose is not a guard."* The seam is free and deterministic: all 79,022 activities carry a non-null
`due_date` spanning 2022-01-13 to 2030-05-07, `dateTo` is an exportable activity key, and
`fetchActivities` applies `lt(dueDate, endOfDayExclusive(dateTo))` — a strictly-nested, daily-resolution
widening knob over fixed data. The ladder APPROACHES and CROSSES; a single at-the-boundary assertion is
explicitly not the criterion.

**SC-5 needs a fresh POSITIVE observation, because the row has never existed.** `audit_log` holds 214
rows and **zero** with `entity_type='export'` — no view export has ever been recorded on this
deployment. An "unchanged count" assertion passes today and proves nothing. So: 0 → 1, the row's
contents asserted, then hard-deleted by its own id and its absence asserted.

Purpose: the phase's headline evidence.
Output: one live file that answers SC-1, SC-2, SC-4 and SC-5, plus the ablation that proves it can fail.
</objective>
