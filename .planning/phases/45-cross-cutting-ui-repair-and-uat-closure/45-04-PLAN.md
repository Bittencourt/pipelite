<objective>
Route every dialog close control through the existing `common.close` key, and add the `Sheet`
primitive the admin drawer needs — with that same treatment applied at creation rather than
retro-fitted.

Purpose: the Radix close button's `sr-only` label renders as "Close" in every locale today, across
roughly 16 call sites. One edit at the primitive fixes all of them; requiring every caller to pass a
label invites the same leak back. And the official `sheet` block ships that exact defect verbatim —
adding it as-is would create a NEW instance of the thing SC-3 forbids, in the same change that fixes
the old ones.

Output: `dialog.tsx` with a `closeLabel` prop at both close sites, a new `sheet.tsx`, and a gate that
also pins `alert-dialog.tsx`'s current (correct) absence of any hardcoded label.
</objective>

Import convention — MANDATORY. This repo uses the UNIFIED `radix-ui@1.4.3` package:
  import { Dialog as SheetPrimitive } from "radix-ui"
`grep -rn "@radix-ui/react-" src/` returns ZERO matches. The shadcn registry block already emits the
unified form, so no import normalisation is needed — but do not "fix" it to the per-package form.

Sheet sizing facts, verified from the block source:
  SheetContent side="left" base classes are `inset-y-0 left-0 h-full w-3/4 border-r … sm:max-w-sm`.
  Passing `className="w-64"` overrides `w-3/4` through tailwind-merge (same `w-` group).
  `sm:max-w-sm` is a different group and survives, but is inert: max-width 384px never reduces a
  256px-wide element. The drawer is therefore 256px at every viewport.
  SheetHeader is `flex flex-col gap-1.5 p-4` with NO border — a caller wanting `p-4 border-b`
  supplies it via className.
