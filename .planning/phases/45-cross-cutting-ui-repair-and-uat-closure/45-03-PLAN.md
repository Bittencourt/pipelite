next-themes@0.4.6:
  - dist/index.mjs begins with the literal `"use client"`, so `ThemeProvider` imports DIRECTLY into
    the async server `src/app/layout.tsx`. There is NO `components/theme-provider.tsx` wrapper in
    this repo and this plan must not invent one.
  - `ThemeProvider` renders `[<ThemeScript/>, children]`. `ThemeScript` is a synchronous inline
    `<script>` that writes `document.documentElement.classList` before hydration.
  - `enableColorScheme` defaults to true and ALSO writes `style="color-scheme: …"` on `<html>`.
    Two attributes the server did not render -> `suppressHydrationWarning` on `<html>` is mandatory.
  - `useState(() => H(m, l))` returns `undefined` when `typeof window === "undefined"`, so `theme`
    is `undefined` during SSR. `value={theme ?? "system"}` is REQUIRED, not decorative.
  - Nested providers are a no-op (`useContext(x) ? <Fragment/> : <V/>`), so mounting one cannot
    break `src/components/ui/sonner.tsx`.
  - Storage key is the default `"theme"` in localStorage. No override, no cookie, no DB column.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser localStorage → CSS class on `<html>` | The only user-controlled value this plan introduces |
| server-rendered HTML → pre-hydration inline script | The script mutates `<html>` before React takes over |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-09 | Tampering | localStorage `theme` value | accept | The value is consumed only as a CSS class name from the closed three-member set light/dark/system. It reaches no server action, no query and no `dangerouslySetInnerHTML` this plan writes. ASVS V5 does not apply |
| T-45-10 | Information disclosure | next-themes `ThemeScript` inline `<script>` | accept | The script is library-authored, is a fixed function body with no interpolated user data, and is rendered with `suppressHydrationWarning`. No project value is interpolated into it |
| T-45-11 | Denial of service | hydration mismatch on `<html>` | mitigate | `suppressHydrationWarning` is asserted present by the source gate. Without it React logs a mismatch and in dev may discard the server HTML — a self-inflicted degraded render |
| T-45-12 | — (accessibility assurance) | sign-out item contrast in dark mode | mitigate | C-1 replaces `text-red-600` (~3.4:1 on the dark popover surface) with `text-destructive`, which carries a lightened dark-mode token. The gate asserts `text-red-` is absent |
| T-45-SC | Tampering | npm installs | mitigate | This plan installs nothing. `next-themes@^0.4.6` is already a recorded dependency |
</threat_model>
